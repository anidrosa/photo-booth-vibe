# Photo Booth Vibe

Sales page for Photo Booth Vibe, an iPad digital photo booth rental in Rockland County, NY.

The page is `index.html`. It's hosted on GitHub Pages.

## Turn on GitHub Pages (one time)

1. In this repo on GitHub, open **Settings**, then **Pages**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Choose branch **main** and folder **/ (root)**, then **Save**.
4. After a minute or two the page is live at `https://anidrosa.github.io/photo-booth-vibe/`.

## Booking links

Every "Check your date" button goes to the contact page on the Zenler site: https://photoboothvibe.newzenler.com/support
